Diberi $110101_2 + p_8 = 324_5$. Hitung nilai $p$.
Given $110101_2 + p_8 = 324_5$. Calculate the value of $p$.
[2 markah / 2 marks]
(b)

State the place value and digit value of digit 4 in the number $2431_5$ in base ten.
[1 markah / 1 mark]
[3 markah / 3 marks]
Marking Criteria
  • (a) Tukar ke asas 10: $110101_2 = 53_{10}$, $324_5 = (3 \times 25) + (2 \times 5) + 4 = 89_{10}$ K1

  • (b) Nilai digit $4 = 4 \times 5^2 = 100$ N1
Marker's Tip: State $p = 44$ (the digits in base 8), not $44_8$ as the variable value.

Q8

Given that $W$ varies directly as the square root of $x$ and inversely as the square of $y$. Given that $W = 6$ when $x = 16$ and $y = 2$.
(a)
Ungkapkan $W$ dalam sebutan $x$ dan $y$.
Express $W$ in terms of $x$ and $y$.
[2 markah / 2 marks]
(b)(i)
Cari nilai $W$ apabila $x = 36$ dan $y = 3$.
Find the value of $W$ when $x = 36$ and $y = 3$.
[1 markah / 1 mark]
(b)(ii)
Cari nilai positif bagi $y$ apabila $W = 2$ dan $x = 64$.
Find the positive value of $y$ when $W = 2$ and $x = 64$.
[2 markah / 2 marks]
[5 markah / 5 marks]
Marking Criteria
  • (a) $W = \frac{k\sqrt{x}}{y^2} \implies 6 = \frac{k\sqrt{16}}{2^2} \implies 6 = \frac{4k}{4} \implies k = 6$ K1

Q9
Satu set data yang mengandungi 5 nombor mempunyai min 8 dan varians 6.4.
A set of data containing 5 numbers has a mean of 8 and a variance of 6.4.
(a)
Cari nilai bagi $\sum x$ dan $\sum x^2$.
Find the values of $\sum x$ and $\sum x^2$.
[2 markah / 2 marks]
(b)(i)
Jika satu nombor baharu, $k = 14$, ditambah ke dalam set data tersebut, hitung min yang baharu.
If a new number, $k = 14$, is added to the data set, calculate the new mean.
[1 markah / 1 mark]
(b)(ii)
Hitung sisihan piawai yang baharu bagi set data tersebut.
Calculate the new standard deviation of the data set.
[2 markah / 2 marks]
[5 markah / 5 marks]
Marking Criteria
  • (a) $\sum x = N \bar{x} = 5 \times 8 = 40$ P1
  • $\sigma^2 = \frac{\sum x^2}{N} - \bar{x}^2 \implies 6.4 = \frac{\sum x^2}{5} - 64 \implies \sum x^2 = 5(70.4) = 352$ N1
  • (b)(i) $\bar{x}_{\text{baru}} = \frac{40 + 14}{6} = \frac{54}{6} = 9$ N1
  • (b)(ii) $\sum x^2_{\text{baru}} = 352 + 14^2 = 352 + 196 = 548$; $\sigma = \sqrt{\frac{548}{6} - 9^2} = \sqrt{91.333 - 81} = \sqrt{10.333}$ K1
  • $= 3.21$ N1
Marker's Tip: The new number of observations $N$ increases from 5 to 6.
